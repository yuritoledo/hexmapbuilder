# Design System: Hexmap Builder

## Source of truth

- The user selects preset `b1oXx8qG` and approves the full React interface migration.
- `components.json` records the shadcn configuration.
- `src/theme.css` contains the generated light and dark tokens, Tailwind imports and local Roboto Slab font.
- `src/components/ui/` contains the components generated by the shadcn CLI.
- `src/App.tsx` composes those components and owns workspace state.
- `src/workspace.css` contains screen layout rules. It does not replace component colors or font families.
- `src/style.css` preserves SVG drawing and print rules.
- The earlier Bestiário vivo direction supplies the map-first workspace structure, not the old Eczar and Source Sans 3 theme.

## Interface

- Use Base UI components with Sera styling.
- Use the preset's neutral background, emerald primary actions and semantic color tokens.
- Use Roboto Slab Variable for interface headings, body text and controls.
- Use Lucide icons with visible action labels.
- Keep the generated component variants. Do not duplicate their states in workspace CSS.
- Use `Button`, `Input`, `NativeSelect`, `Checkbox`, `Field`, `Separator` and `Badge` from `src/components/ui/`.
- Keep generation and print actions primary. Use outline buttons for history, files and individual rerolls.
- Retain native selects for the small, fixed terrain and category lists.
- Give every input a visible field label. Field groups identify the print settings.
- Keep the native JSON file input separate from its visible import button.
- The theme includes dark tokens. The product does not expose a theme switch.

## Layout

- Desktop uses preparation, map and consultation columns.
- The workspace uses columns of 225px, flexible space and 252px, with 32px gaps.
- The app width is at most 1600px. Desktop side gutters are 40px.
- At 1200px and below, gutters become 24px. Side columns become 195px and 225px, with 24px gaps.
- At 900px and below, gutters become 16px. The workspace order is map, consultation, preparation and digital key.
- The small-screen links jump to Mapa, Consultar and Gerar.
- Header actions wrap with visible text instead of an icon-only menu.
- Selecting a hexagon brings its consultation entry into view on small screens.
- The selected coordinate uses primary and primary-foreground tokens.
- The digital key retains its horizontal table scrolling on narrow screens.

## Map and print isolation

- Preserve the approved 108-cell, 9 × 12 pointy-top grid.
- Preserve the terrain vectors, danger units, permanent central base and optional river.
- Keep the map ink `#252720`, muted ink `#5b5e53` and original monochrome symbols.
- Do not apply emerald tokens to the map or printed sheets.
- Preserve Literata Variable for SVG titles and coordinates.
- Preserve Helvetica Neue, Helvetica, Arial and sans-serif for map body text and the printed key.
- The print-key title uses Literata at 20pt, weight 450. Section headings use Georgia at 12pt.
- The key body uses 9.2pt with line-height 1.32.
- The default region prints on two A4 portrait pages. Long edited content can require additional pages without truncation.
- The map is 210 × 297mm. The key uses a 186mm content width and 12mm margins.
- The key has four columns of 27 rows, 4mm gaps, 3.65mm body rows and 5mm header rows.
- Coordinate columns are 15mm. Danger columns are 10mm.
- A separate two-column list prints full categories and names, including the permanent base.
- Shared handwriting space uses the remaining key height, with a 40mm minimum.
- Print visibility settings affect only the map. The key keeps all information.
- `beforeprint` builds a separate output tree. `afterprint` removes it.

## Accessibility and behavior

- Keep the skip link, visible labels, status messages and keyboard focus.
- Only one hexagon is in the grid's tab sequence.
- Arrow keys move focus without changing selection. Enter and Space select. Home and End move within the row.
- A solid selected border and dashed focus border communicate state without color alone.
- Controlled Base UI checkboxes follow undo, redo and print preferences.
- Preserve local data, JSON validation and the session history contract.
- A corrupt saved map stays untouched until the user confirms replacement.
- The retry-save action appears only after recovery or write failure.
